# AI Resume Analyzer

An AI-powered Resume Analyzer that compares a candidate's resume with a Job Description using NLP and Machine Learning.

## Features

- ATS Score Calculation
- Resume Parsing
- Job Description Parsing
- Keyword Matching
- Semantic Similarity
- AI Resume Suggestions
- Interactive Dashboard
- Charts
- SQLite History
- PDF Report Generation

## Tech Stack

### Backend
- Python
- FastAPI
- SQLite
- Sentence Transformers
- spaCy
- Scikit-learn

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- Recharts
